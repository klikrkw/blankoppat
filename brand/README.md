# Blanko PPAT — Logo & Brand Assets

Folder ini berisi file logo aplikasi **Blanko PPAT**.

## File

| File | Kegunaan | Latar |
|---|---|---|
| `logo-blankoppat.svg` | Logo utama (ikon + teks) | Terang |
| `logo-blankoppat-dark.svg` | Logo untuk latar gelap (teks putih) | Gelap |
| `logo-blankoppat-icon.svg` | Ikon saja (tanpa teks), sudut membulat | Bebas |
| `logo-blankoppat-monochrome.svg` | Monokrom putih (sablon/print) | Gelap |
| `logo-blankoppat.png` | Ekspor PNG logo utama (1600 px) | Transparan |
| `logo-blankoppat-dark.png` | Ekspor PNG logo gelap (1600 px) | Navy |
| `logo-blankoppat-512.png` | Ekspor PNG ikon 512×512 | Gelap |
| `logo-blankoppat-1024.png` | Ekspor PNG ikon 1024×1024 | Gelap |

## Makna desain

- **Lembar dokumen** — akta/blanko PPAT.
- **Lipatan sudut** — template yang bisa disesuaikan.
- **Stempel biru dengan centang** — legalitas, validasi, dan hasil yang selesai.

## Aturan pakai

- Ruang kosong minimal di sekeliling logo = tinggi huruf "B".
- Ukuran minimum logo utama: 120 px lebar (digital), 25 mm (cetak).
- Ukuran minimum ikon: 24 px.
- Jangan miringkan, regangkan, ganti warna di luar palet, atau beri bayangan tambahan.
- Pada latar gelap gunakan `logo-blankoppat-dark.svg`; pada latar terang gunakan `logo-blankoppat.svg`.
- Untuk avatar/favicon gunakan `logo-blankoppat-icon.svg`.

## Font

- **Poppins Bold** — wordmark "Blanko PPAT".
- **Poppins Medium / Inter Regular** — subteks.

## Catatan teknis

- Semua file SVG memakai vektor penuh (kecuali teks pada logo utama yang tetap berupa teks agar mudah diedit).
- Jika akan dicetak atau dipakai di aplikasi pihak ketiga yang tidak mendukung font, ubah teks menjadi outline lebih dulu (Canva/Figma/Illustrator).
